    Export
    
        
    Copies every item you have in stock as CSV text, one line each,

    Import
    
        
    Paste one line per item:
          action,item,quantity,unit,location
    
          add adds to an item with the same name and location, or creates it.
          remove takes away, and anything that reaches 0 goes on the To buy list.
          Unit and location can be left empty. A header line is skipped.
